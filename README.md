# TEST MY HOLES

A minimal GitHub Pages deployment test stored in the IGNITE vault.

## Workflow

1. Edit files locally.
2. Commit and push to the private GitHub repository.
3. GitHub Actions deploys `main` to GitHub Pages.
4. Refresh the stable URL to view the current deployment.

## Files

- `index.html` — page structure
- `styles.css` — presentation
- `app.js` — live viewed-at timestamp
- `.github/workflows/pages.yml` — automatic Pages deployment

The stable URL will be recorded here after the first verified deployment.
